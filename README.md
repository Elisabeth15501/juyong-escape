# 居庸关 · 逃 juyong-escape

> 《朱厚照出居庸关·逃》—— 8-bit 像素风横版跑酷。躲避巡关御史张钦，拾取「大将军印」
> 化身威武大将军朱寿，闯过居庸关。张钦追之不及，痛哭失声。
>
> **当前版本 v0.9.3**（2026-08-31）｜ 更新详情见 [RELEASE_NOTES.md](./RELEASE_NOTES.md)
> ｜ 八幕关卡规划见 [dev_plan.md](./dev_plan.md)

纯前端实现：原生 HTML5 Canvas 2D + Vanilla JS，**零框架、零构建、零网络请求**，
按小红书小工具规范开发（外置脚本 / addEventListener / 无 eval）。

## 玩法

### 出关记（关卡模式）
3 幕叙事（数据驱动，可扩展至 8 幕），每幕前后穿插《明史·张钦传》《明武宗实录》典故卡：

| 幕 | 典故 | 玩法要点 |
|---|---|---|
| 一 · 起心动念 | 武宗欲出关巡边，张钦等力谏 | 教学关，引导拾印变身 |
| 二 · 关门对峙 | 张钦闭关门、收钥藏之，仗剑坐关下 | 障碍渐密，锁与奏折登场 |
| 三 · 出关·痛哭失声 | 趁张钦巡白羊口，疾驰出关 | 终局：撞碎关门（隐藏成就【威武大将军】+ 应州大捷彩蛋）或谷大用开门，随后张钦痛哭演出 |

### 居庸关（无限跑酷）
速度随奔袭里数递增，比拼最远记录（localStorage 存档）。

### 核心机制
- **变身**：拾「大将军印」→ 朱寿形态 6 秒，无敌 + 提速 + 撞碎障碍；第三幕保底必出印。
- **障碍四型**：
  - 侍卫（地面，跳过）
  - 锁（地面，掷出）
  - 奏折（空中飞行，需起跳躲避）
  - **张钦（追击型 BOSS）**：巡逻 → 普通形态碰到触发追击（0.9s 宽限）→ 横向扑向玩家
    （不会跳跃，跳过可甩开）→ 追击中撞上侍卫/锁会被撞晕退场；变身朱寿可直接撞碎。
    关卡模式第二、三幕登场；无限模式过 120 里后登场；全场唯一。

## 运行

```bash
cd juyong_escape
python3 -m http.server 8000
# 浏览器打开 http://localhost:8000
```

桌面横版 480×270；手机竖屏自动切换 270×480 竖版布局。键盘空格 / 鼠标 / 触摸均可跳跃。

## 技术要点

- **竖屏自适应**：按窗口宽高比切换横/竖布局，游戏途中转屏不中断
- **高清渲染**：画布位图匹配设备像素（DPR），大屏不发糊；精灵最近邻缩放保像素感
- **音效**：Web Audio 运行时合成 8-bit 方波，零音频文件
- **合规**：脚本外置、零外链、零 eval —— 可直接按小红书小工具规范打包（zip ≤ 10MB）
