# 朱厚照出居庸关·逃

> 8-bit 像素风横版跑酷。正德十二年，武宗朱厚照微服出京，要抢在巡关御史张钦眼皮底下闯出居庸关；
> 拾取「大将军印」化身朱寿，撞碎关门、直奔应州。张钦追之不及，痛哭失声。
>

## 项目简介

纯前端像素跑酷，零框架、零构建、零网络请求。玩法一句话：**点按跳矮，长按跳高**——全部决策
就是跳跃的时机与高度。关卡模式 3 幕叙事，穿插《明史》典故卡；无限跑酷模式比拼最远奔袭记录。

史实依据：张钦闭门收钥、仗剑坐关（「敢言开关者，斩！」）；武宗微服至昌平、趁张钦巡视白羊口
疾驰出关、谷大用守关断其追路；出关后以朱寿之名指挥应州之战——均出自
《明史·张钦传》《明史·武宗本纪》及《明武宗实录》。

## 游戏玩法

**操作就一个：点击跳跃。点按跳矮，长按跳高。**

按下起跳，按住越久跳得越高（提前松手会截断上升）。落地时机与按键时长即全部决策：
跳过侍卫、躲开奏折、甩掉张钦。

### 出关记（关卡模式）

3 幕叙事（数据驱动，可扩展至 8 幕），每幕前后穿插《明史·张钦传》《明武宗实录》典故卡：

| 幕 | 典故 | 玩法要点 |
|---|---|---|
| 一 · 起心动念 | 武宗欲出关巡边，张钦等力谏 | 教学关，引导拾印变身 |
| 二 · 关门对峙 | 张钦闭关门、收钥藏之，仗剑坐关下 | 障碍渐密，锁与奏折登场 |
| 三 · 出关·痛哭失声 | 趁张钦巡白羊口，疾驰出关 | 终局：撞碎关门（隐藏成就【威武大将军】+ 应州大捷彩蛋）或谷大用开门，随后张钦痛哭演出 |

### 居庸关（无限跑酷）

速度随奔袭里数递增，比拼最远记录（localStorage 存档）。

### 核心机制

- **变身**：拾「大将军印」→ 朱寿形态 6 秒，无敌 + 提速 + 撞碎障碍；第三幕保底必出印。
- **障碍四型**：
  - 侍卫（地面，跳过）
  - 锁（地面，掷出）
  - 奏折（空中飞行，需起跳躲避）
  - **张钦（追击型 BOSS）**：巡逻 → 普通形态碰到触发追击（0.9s 宽限）→ 横向扑向玩家
    （不会跳跃，跳过可甩开）→ 追击中撞上侍卫/锁会被撞晕退场；变身朱寿可直接撞碎。
    关卡模式第二、三幕登场；无限模式过 120 里后登场；全场唯一。

## 技术栈

- **渲染**：HTML5 Canvas 2D，Vanilla JS，零框架、零构建、零网络请求
- **音效**：Web Audio 运行时合成 8-bit 方波，零音频文件
- **引擎**：数据驱动——`LEVELS[]` 关卡数据 + `SHEET_FRAMES` 精灵帧数配置，加关不碰引擎
- **自适应**：按窗口宽高比切换横/竖布局，游戏途中转屏不中断
- **高清**：画布位图匹配设备像素（DPR），大屏不发糊；精灵最近邻缩放保像素感
- **合规**：脚本外置、零外链、零 eval —— 按小红书小工具规范打包（zip ≤ 10MB）

### 自定义美术（可选）

代码内置占位像素小人，缺图也能跑。把 8-bit 精灵表 PNG 放入**项目根目录**即自动替换
（文件名与帧数约定见 `game.js` 顶部 `ASSETS` 说明）：透明背景，横排帧。

- `Zhuhouzhao.png`（朱厚照，4 帧）· `Zhushou.png`（朱寿，4 帧）
- `Shiwei.png`（侍卫，1 帧）
- `Zhangqin_standing.png`（张钦站立，1 帧）· `Zhangqin.png`（张钦追击，4 帧）
- `Zhangqin_crying.png`（张钦痛哭，8 帧，终局演出）
- `scene_palace.png` / `scene_road.png` / `scene_pass.png`（三幕像素画背景，1024×576）
- 缺失任意一张 → 对应元素自动回退为程序化绘制（背景）或代码占位（角色）

## 本地运行方式

```bash
cd juyong_escape
python3 -m http.server 8000
# 浏览器打开 http://localhost:8000
```

桌面横版 480×270；手机竖屏自动切换 270×480 竖版布局。键盘空格 / 鼠标 / 触摸均可跳跃。
